# ULTIMATE ANTI-FLOOD 2.0 PROTECTION
Высокопроизводительная защита от флуда для серверов CS 1.6 (ReHLDS/ReAPI).

## Описание
Оптимизированная версия 2.0, предназначенная для блокировки различных типов сетевых атак и спама командами.

## Основные возможности
* **Anti-Flood:** Эффективная блокировка спама командами.
* **Optimization:** Код оптимизирован для работы под высокими нагрузками (ReAPI).
* **Author:** KOHAH_Style.

## Требования
* ReHLDS
* ReAPI
* AMX Mod X 1.9.0 или выше
