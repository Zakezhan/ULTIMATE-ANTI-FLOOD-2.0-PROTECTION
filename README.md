## Описание
Высокопроизводительная защита серверов Counter-Strike 1.6 от флуда и сетевых атак. Плагин Ultimate Anti-Flood 2.0 для ReHLDS и ReAPI. Оптимизированный код от KOHAH_Style для работы под высокой нагрузкой без лагов.

## Основные возможности
* **Anti-Flood:** Эффективная блокировка спама командами.
* **Optimization:** Код оптимизирован для работы под высокими нагрузками (ReAPI).
* **Author:** KOHAH_Style.

## Требования
* ReHLDS
* ReAPI
* AMX Mod X 1.9.0 или выше
